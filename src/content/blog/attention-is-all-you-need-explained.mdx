2017 年，Google Brain 团队发表了这篇改变深度学习历史的论文。它提出了 Transformer 架构，完全基于注意力机制，抛弃了 RNN 和 CNN。

## 核心问题

在 Transformer 之前，序列建模主要依赖 RNN（如 LSTM、GRU）。RNN 的根本问题是**顺序处理**——必须逐步计算，无法并行化。

```
h_t = f(h_{t-1}, x_t)  # 每一步依赖前一步
```

这导致两个严重问题：
1. **训练速度慢**：无法并行处理序列
2. **长距离依赖困难**：梯度消失/爆炸

## Transformer 的核心思想

Transformer 的关键洞察：**可以用注意力机制直接建模序列中任意两个位置的关系**，不需要递归。

```
Attention(Q, K, V) = softmax(QK^T / √d_k)V
```

### 自注意力机制

自注意力让每个位置都能"看到"序列中的所有其他位置：

```
输入: "The cat sat on the mat"
                 ↓
    每个词计算与所有词的相关性
                 ↓
    加权聚合相关信息
```

**直觉理解**：就像阅读时，你会根据上下文理解每个词的含义。"bank" 在 "river bank" 和 "bank account" 中含义不同，自注意力能捕捉这种依赖。

### 缩放点积注意力

```python
def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = K.shape[-1]
    scores = Q @ K.T / math.sqrt(d_k)  # 缩放
    
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    
    weights = F.softmax(scores, dim=-1)
    return weights @ V
```

**为什么要除以 √d_k？** 当维度较大时，点积值会很大，导致 softmax 进入饱和区，梯度接近零。缩放保持梯度稳定。

## 多头注意力

单个注意力头只能捕捉一种关系模式。多头注意力让模型同时关注不同类型的关系：

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h)W^O

where head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
```

**直觉**：一个头可能关注语法关系，另一个关注语义关系，第三个关注位置关系。

## 位置编码

Transformer 没有递归，所以需要额外注入位置信息：

```
PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

**为什么用正弦函数？** 因为它能表示相对位置——PE(pos+k) 可以用 PE(pos) 的线性变换表示。

## 编码器-解码器架构

```
编码器 (6层):
┌─────────────────────┐
│  Multi-Head Attention │
│  Add & LayerNorm     │
│  Feed Forward        │
│  Add & LayerNorm     │
└─────────────────────┘

解码器 (6层):
┌─────────────────────┐
│  Masked Multi-Head   │  ← 防止看到未来
│  Add & LayerNorm     │
│  Cross-Attention     │  ← 关注编码器输出
│  Add & LayerNorm     │
│  Feed Forward        │
│  Add & LayerNorm     │
└─────────────────────┘
```

**关键创新**：
- **残差连接**：解决深层网络训练困难
- **层归一化**：稳定训练
- **掩码注意力**：解码时防止"偷看"未来

## 为什么它如此成功？

1. **并行化**：训练速度比 RNN 快一个数量级
2. **长距离依赖**：任意两个位置直接连接
3. **可扩展性**：参数增加时性能持续提升
4. **通用性**：不仅用于 NLP，还扩展到视觉、音频

## 总结

Transformer 的伟大之处在于它的**简洁性**——用一个统一的注意力机制替代了复杂的递归结构。这种简洁带来了更好的并行性、更强的表达能力和更广的适用性。

理解这篇论文，是理解现代深度学习的基础。
